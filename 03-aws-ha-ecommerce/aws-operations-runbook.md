# AWS Operations Runbook

## Daily
- Check ALB target health
- Check ASG instance count and anomalies
- Check RDS CPU/connections/storage alarms

## Weekly
- Patch AMIs / refresh launch template
- Review security findings and IAM drift
- Backup verification

## Monthly
- Capacity tuning (ASG/RDS)
- Cost optimization review
- Failover drill and incident playbook rehearsal
