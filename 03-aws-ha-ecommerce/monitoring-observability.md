# Monitoring and Observability

## Golden Signals
- Latency
- Traffic
- Errors
- Saturation

## Infra Metrics
- CPU, memory, disk IOPS, network throughput
- Load balancer healthy/unhealthy hosts
- DB connections, replication/failover events

## Security Signals
- Repeated auth failures
- Privilege changes
- Critical vulnerabilities by asset

## Alerting Standards
- P1 alerts: page on-call immediately
- P2 alerts: notify with ack SLA
- Alert fatigue control via dedup/grouping
