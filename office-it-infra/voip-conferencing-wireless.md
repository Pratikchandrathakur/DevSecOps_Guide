# VoIP, Conferencing, and Wireless Implementation Guide

## VoIP
- VLAN separation for voice traffic
- QoS priority for RTP/SIP
- SBC/secure trunking recommendations

## Conferencing
- Certified room devices
- Dedicated bandwidth classes
- Monitoring for packet loss and jitter

## Wireless
- WPA3 where supported
- Separate SSIDs: Corp, Guest, IoT
- NAC posture checks for corp SSID
