# Patch Management SOP

## Scope
OS, runtime, dependencies, container base images, and network appliances.

## Cadence
- Critical: within 24–48h
- High: within 7 days
- Medium: within planned monthly cycle

## Workflow
1. Identify patches
2. Risk assessment
3. Stage testing
4. Maintenance window deployment
5. Validation and rollback readiness
6. Compliance reporting
